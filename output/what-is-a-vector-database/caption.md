Ever wondered how a search can find "budget airfare" when you typed "cheap flights"? The answer is a vector database.

Here is the idea in plain terms. Text can be turned into a list of numbers that captures what it means. Each list is a vector. Sentences with similar meaning end up with similar numbers, so they sit close together, like dots on a map.

A vector database stores millions of these dots. When you give it a new one, it returns the nearest matches in a fraction of a second. No exact words needed.

It's already behind chatbots that look up your documents and behind many product suggestions. Now you know what's doing the work.
